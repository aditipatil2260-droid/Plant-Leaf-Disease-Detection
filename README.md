# 🌿 Plant Leaf Disease Detection

## 📌 Project Overview
Plant Leaf Disease Detection is an AI-based project that identifies plant leaf diseases from uploaded images using Deep Learning.

## 🎯 Objectives
- Detect plant leaf diseases from images.
- Predict the disease using a trained deep learning model.
- Display the predicted disease and confidence score.

## 🛠️ Technologies Used
- Python
- TensorFlow and Keras
- Streamlit
- NumPy
- Pillow (PIL)

## 🧠 Model
MobileNetV2-based Deep Learning Model

## ✨ Features
- Upload a plant leaf image.
- Predict the disease.
- Display prediction confidence.

## 🚀 How to Run
1. Install the required libraries.
2. Keep `app.py`, `class_names.json`, and `plant_leaf_disease_model.keras` in the same folder.
3. Run the application using:

   `streamlit run app.py`
